# Изменения — версия 8

- Разделили монолитный `index.html` на HTML, CSS и три JS-модуля (сборка не нужна).
- Сохранили ключ `ord_v3`, схему пациентов/обходов/результатов и разметку функций исходного ZIP.
- Автосохранение полей, сохранение черновиков обходов, анализов, задач, событий.
- Проверка повреждённых JSON/форматов и запрет на автоматическое затирание повреждённого хранилища.
- Резервные копии JSON, импорт с подтверждением и функцией сохранения повреждённого оригинала.
- Безопасное экранирование HTML и безопасный делегированный обработчик событий без inline onclick.
- Исправлены локальные даты (вместо UTC), генерация ID, обработка ошибок localStorage.
- Удаление связанных задач/событий при удалении пациента, возможность удаления отдельных задач и событий.
- Проверка числовых полей обхода и защита от пустых записей.
- Улучшен PWA-кэш: явный список ресурсов, новый номер версии, ограничение своим origin/scope.
- Переписаны инструкции публикации, архив содержит файлы непосредственно в корне.

Известные ограничения: локальные незашифрованные данные; нет истории версий и аудита изменений; графики используют равные интервалы между записями (не точную шкалу времени); нельзя использовать для реальной клинической работы.
