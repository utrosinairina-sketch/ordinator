# Изменения v10 (25.10.2026)

## Добавлено

- Российское оформление текстовых дат (`дд.мм.гг`) и подписи к встроенным date-полям с русским представлением.
- Выбор нескольких показателей для совмещённого графика с цветами, легендой, индивидуальными шкалами измерений, датами на оси X и списками исходных значений. Лабораторные группы показываются в порядке раздела «Лаборатория».
- Таблица экспресс-ввода анализов по пациенту и дате непосредственно под календарём. Один общий «Сохранить». Проверка значений перед записью, сохранение старых комментариев, отсутствие автоматического удаления пустых записей и дубликатов при повторном сохранении.
- Вкладка «Библиотека препаратов» вместо нижней «Задачи» — карточки препаратов, привязка PDF из ГРЛС вручную, локальное хранение двоичного файла в IndexedDB, извлечение доступного текстового слоя через Mozilla PDF.js CDN.
- Перенос МНН/торгового названия/формы/группы в терапию через выбор пациента и прямой выбор препарата из терапевтической формы; доступ к связанному PDF из назначения. Дозы не переносятся автоматически.
- Предварительное сравнение числового результата с самостоятельно настроенными референсными границами: ниже / в пределах / выше.
- Старые задачи и возможность добавления новых перенесены внутрь календаря.

## Совместимость

- Прежний ключ `localStorage: ord_v3` сохранён; схема 5 → 6, данные v7/v8/v9 читаются без пересоздания.
- Внутренние даты и идентификаторы не менялись; новая библиотека создаётся только при добавлении карточек.
- PDF не включается в JSON-копию, его нужно хранить отдельно.

## Условия

- ГРЛС не интегрирован API и официальные PDF автоматически не загружаются.
- OCR сканированных PDF не реализован. Извлечение текста требует сети и может ошибаться.
- Для реальной медицинской информации нет защищённого хранения и контроля доступа.
