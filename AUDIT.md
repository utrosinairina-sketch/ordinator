# Проверки и ограничения v10

## Программные проверки

- Node.js: синтаксическая проверка ES-модулей пройдена (включая app.js как .mjs).
- Модульные проверки: преобразование дат, график нескольких числовых рядов, порядок дат и цвета, анализ заголовков текстового PDF, чтение старого состояния схемы 5, массовое добавление/исправление анализов и повторное сохранение без дубликатов.
- Chromium headless в изолированном тесте DOM (ES-модули загружены как data URLs, localStorage имитировано; без доступа к публичному адресу): успешно показан пациент старого формата, открыт календарь, существующий анализ изменён с сохранением предыдущей даты, создан новый анализ, на одном графике отображены два показателя (3 сохранённые точки), создан препарат библиотеки, выбран пациент и данные препарата перенесены в терапию, доза осталась пустой. JS-ошибок во время этих сценариев не выявлено.

## Что не проверялось как работающее на реальном сайте

- Открытие на GitHub Pages / на реальном Android, обновление service worker в реальных браузерах.
- PDF-инструкции из ГРЛС: ни одной реальной инструкции не приложено к текущему запросу. Проверена только логика извлечения тестовых заголовков и код прикрепления; реальная цепочка PDF.js CDN + IndexedDB и качество извлечения на реальных PDF пока не проверены.
- Автоматическое OCR PDF-сканов не предусмотрено.
- Полная клиническая валидация референсов, противопоказаний, взаимодействий, всех медицинских подсказок не проводилась.

## Критические правила

- Референсы лабораторий требуют проверки методов, биоматериала, возраста и пола. Программа не содержит достоверных универсальных нормативов.
- Разные единицы измерения в «Динамике» имеют **разные шкалы**, рядом обозначены реальные числовые значения/единицы.
- Ненаписанное значение не равно нулю; при нескольких измерениях за день массовое обновление неоднозначной записи блокируется.
- Старые задачи сохранены в том же state.tasks; старые записи результатов не мигрируются разрушительным способом.
- JSON-копия НЕ включает файлы PDF; они хранятся в IndexedDB браузера. Перед сменой устройства их нужно скачивать дополнительно.
- Использовать только обезличенные тестовые данные; приложение не обеспечивает защиту медицинской тайны.
