# Ординатор — мобильный PWA-прототип, версия 3

## Размещение на GitHub Pages
Замените в корне репозитория `index.html`, `manifest.webmanifest`, `sw.js` и `README.md` файлами из этой папки. Сохраните все файлы в ветке `main` в корне репозитория. GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Новое в версии 3
- Карточка пациента с полями ФИО/условное обозначение, палата, дата поступления, диагноз.
- Осмотр по системам: общее состояние, сердечно-сосудистая, дыхательная, ЖКТ, мочевыделительная, нервная системы, рана и дренажи, кровь и гемостаз, прочее.
- Для каждой системы — поля физикального осмотра и отдельный комментарий.
- Лабораторные результаты с датой, текущим и предыдущим значением, комментарием и отметкой внимания.
- Инструментальные исследования с датой, заключением/данными, предыдущим результатом и отметкой внимания.
- История результатов, календарь событий, задачи, локальное хранение и PWA.

## Важно
Демонстрационный прототип, не предназначенный для реальных медицинских или идентифицирующих данных. Хранение локальное в браузере, без шифрования, аккаунтов, синхронизации или резервного копирования. Публичный сайт не является медицинской информационной системой.


## Версия 4: данные по системам
Лабораторные и инструментальные записи добавляются внутри соответствующей системы организма; физикальный осмотр также сгруппирован по системам. У каждой записи есть дата, текущий результат, предыдущий результат, отметка внимания и комментарий. Старые записи без категории отображаются в разделе «Прочее».
