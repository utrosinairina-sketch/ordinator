# Ординатор v10 — статический сайт для GitHub Pages

Работает без React, npm и сборки: обычные HTML/CSS/ES-модули JavaScript. Для запуска распакуйте содержимое архива **в корень папки**, откройте папку в VS Code, используйте **Live Server** через `index.html`. Нельзя запускать двойным кликом по `file://` из-за ES-модулей.

## Перед обновлением

1. На СТАРОЙ версии откройте «Пациенты → Скачать копию JSON» и сохраните файл в безопасном месте.
2. Не очищайте браузер, localStorage и IndexedDB; публикация ZIP сама по себе старые данные не удаляет.
3. В VS Code распакуйте и подмените файлы новой версии с сохранением структуры `js/` и `sw.js`.
4. Сначала проверьте на вымышленных пациентах через Live Server, затем публикуйте распакованные файлы в GitHub Pages.
5. Для пользователей уже опубликованного сайта обязательно важно: `http://127.0.0.1:5500`, `https://имя.github.io/проект/` и разные браузеры имеют **разные хранилища**. Данные между ними не переходят сами — пользуйтесь резервной JSON-копией.

## Новые возможности

- **Даты**: во всех текстовых представлениях выводится `25.10.26` либо `25.10.26 14:30`. Внутри хранилища даты остались `2026-10-25` для сортировки и совместимости. Возле нативного поля выбора даты показывается русский вариант. Сам вид системного календарного элемента контролирует браузер / ОС и может отличаться.
- **Динамика**: чекбоксы позволяют выбрать сразу несколько показателей, включая разные источники. Лабораторные показатели сгруппированы в том же порядке, что и в карточке пациента. Каждый показатель окрашен в свой цвет; общая временная ось показывает дату каждого фактически сохранённого измерения (прокрутка по горизонтали). Для разных единиц измерения используются **раздельные шкалы**; точки не соединяются выдуманными измерениями.
- **Календарь**: ниже сетки есть «Лаборатория за одну дату». Выберите пациента и дату, заполните в одной таблице только числовые значения и нажмите «Сохранить». Пустые поля ничего не удаляют. Если на выбранную дату есть ровно одно измерение этого показателя без времени, оно обновляется; если несколько, автоматическая правка запрещается и выполняется из карточки пациента. Старые записи из других дат не меняются.
- **Библиотека**: заменяет нижнюю вкладку «Задачи». В библиотеке можно сохранить карточку препарата: МНН, торговое название, форма, группа, номер регистрации, ссылка на официальный ГРЛС и PDF инструкции. PDF прикрепляется вручную из файла, скачанного пользователем из ГРЛС. Кнопка «В терапию» переносит сведения после **явного выбора пациента**; дозировку, путь введения и режим приёма врач заполняет самостоятельно. В «Терапии» есть также селектор «Препарат из библиотеки» и доступ к PDF для связанных назначений.
- **Референсы**: на экране «Пациент → Лаборатория» открыта настройка нижней и верхней границ для каждого анализа. При вводе числа показывается предварительное сравнение «выше / ниже / в пределах». Если отсутствует метод/биоматериал/применимость, это не является клинически подтверждённой оценкой. Сохранённые старые референсные снимки не переписываются.
- **Задачи**: исторические задачи сохранены. В календаре есть блок для их добавления, на выбранных датах отображаются старые задачи и события.

## Работа с официальными инструкциями

1. Откройте https://grls.rosminzdrav.ru/ и найдите **конкретный зарегистрированный препарат** и его форму / дозировку.
2. Скачайте подходящую инструкцию PDF и сохраните страницу ГРЛС, с которой она получена.
3. В приложении перейдите в «Библиотека», укажите МНН / торговое название, ссылку на ГРЛС, прикрепите PDF. Подтвердите источник **только если самостоятельно сверили** препарат с официальной записью.
4. PDF сохраняется локально в IndexedDB этого браузера; имя и отобранные фрагменты текста — в `ord_v3`. Кнопка PDF в карточке скачивает документ.
5. Для автоматического извлечения текстового слоя PDF требуется интернет: Mozilla PDF.js подгружается с CDN при импорте. Если скан без текста, сеть недоступна или распознавание не удалось, **сам PDF всё равно сохраняется**, но текстовые разделы не заполняются автоматически. Содержание необходимо проверить с оригиналом.

**Ограничения:** программа **не скачивает инструкции из ГРЛС автоматически**, не подтверждает подлинность файла и не заполняет всю библиотеку без предоставленных пользователем PDF. ГРЛС может содержать разные инструкции для различных форм и регистраций. Никогда не полагайтесь на импортированные фрагменты без проверки оригинального PDF. Импортированные фрагменты не используются для автоматического назначения дозы, проверки взаимодействий или противопоказаний.

**Резервная копия JSON НЕ включает двоичные PDF.** PDF нужно сохранить дополнительно (можно повторно скачать кнопкой карточки). Если открыть сайт на другом устройстве/в другом браузере, PDF нужно загрузить заново. `localStorage` также зависит от домена; GitHub Pages не синхронизирует его между устройствами.

## Структура проекта

```
index.html                  HTML навигация
styles.css                  оформление + адаптация к телефону
js/app.js                   интерфейс, действия и связывание данных
js/clinical.js              группы анализов / препаратов и клинические формулы
js/catalog.js               унаследованные справочники и поля
js/storage.js               совместимость, JSON-копии, localStorage
js/dates.js                 русский формат даты в интерфейсе
js/charts.js                многоцветный график нескольких серий
js/dynamics.js              чтение исходных измерений для графика
js/pdf_store.js             локальные PDF, извлечение текстового слоя
js/excel.js                 импорт Excel/CSV из v9
manifest.webmanifest        метаданные сайта
sw.js                       версия офлайн-кэша интерфейса
README.md                   инструкция
AUDIT.md                    проверки / ограничения
CHANGELOG.md                изменения
```

## Безопасность

Это **не защищённая медицинская информационная система**: данные пациентов хранятся в браузере без шифрования, ролей пользователей, сервера и полноценного аудита. Не вводите реальные ФИО/диагнозы/иную идентифицирующую медицинскую информацию. Не загружайте на публичные ресурсы медицинские файлы с персональными данными. Автоматические предупреждения не заменяют клинический контроль.
