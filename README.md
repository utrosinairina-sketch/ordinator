# Ординатор — мобильный PWA-прототип

## Первая версия
- Главный экран «Сегодня»: пациенты, незакрытые задачи и события на текущую дату.
- Отдельные карточки пациентов.
- Задачи с датой, сроком и отметкой выполнения.
- Календарь задач и событий.
- Крупные кнопки и нижняя навигация, рассчитанные на телефон.

## Запуск
PWA нужно разместить на HTTPS-хостинге, затем открыть ссылку в Chrome на Android и выбрать «Установить приложение» или «Добавить на главный экран», если доступно. Открытие index.html как локального файла не обеспечивает полноценную установку PWA.

## Ограничения безопасности
Это прототип, не медицинская информационная система. Не вводить ФИО, номера историй болезни, даты рождения, клинические результаты и другие данные реальных пациентов. Данные сохраняются в localStorage браузера без шифрования, не синхронизируются и могут быть потеряны. Нет учётных записей, ролей, аудита или защищённого серверного резервного копирования. Перед использованием в клинике необходимы согласование с больницей, оценка защиты данных и полноценная безопасная реализация.
