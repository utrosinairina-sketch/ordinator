ОРДИНАТОР — версия с вкладкой «Терапия»

Содержимое:
- index.html — существующее приложение с добавленной вкладкой «Терапия».

Что добавлено:
- вкладка «Терапия» в нижней навигации;
- терапия внутри карточки конкретного пациента;
- группировка действующих назначений по фармакологическим группам;
- добавление и редактирование назначения;
- проверка полноты/формата и экран подтверждения «Было → Стало»;
- сохранение старой и новой версии в общей истории и истории препарата;
- отмена назначения отдельным подтверждаемым событием без удаления из истории;
- сравнение двух файлов или двух листов Excel, а также CSV;
- предупреждение, что отсутствие препарата во втором источнике не доказывает отмену;
- черновые проверки полноты, без автоматических дозовых рекомендаций.

Как поставить на GitHub Pages:
1. Сохрани копию текущего index.html на случай возврата.
2. Открой репозиторий https://github.com/utrosinairina-sketch/ordinator
3. Открой файл index.html и выбери Edit (значок карандаша) либо Add file → Upload files.
4. Замени только index.html на файл из этого пакета. Другие файлы не удаляй.
5. Сделай Commit changes и дождись завершения публикации GitHub Pages.
6. Открой https://utrosinairina-sketch.github.io/ordinator/ и обнови страницу. Если видна старая версия, попробуй открыть в приватной вкладке или очистить кэш сайта.

Ограничения и безопасность:
- Эта сборка не была загружена в ваш GitHub и не опубликована автоматически. Для публикации требуется действие владельца репозитория.
- Назначения хранятся в localStorage браузера. Это не защищённое медицинское хранилище и данные могут потеряться при очистке данных сайта или смене устройства.
- Не вводи реальные идентифицирующие данные пациентов в публичный прототип.
- XLSX/XLS читается локально в браузере при доступной библиотеке SheetJS, загружаемой с CDN; CSV работает без неё. Сам код сравнения не отправляет содержимое файлов на сервер.
- Клинические взаимодействия, дозы и противопоказания автоматически не проверяются. Предупреждения касаются полноты и формата данных; окончательное решение остаётся за врачом.
- До использования в реальной клинической работе нужны независимое тестирование, защищённое хранение и проверка соответствия применимым требованиям.
